Diccionario completo

Aquí están reunidos todos los conceptos de LuaLex.

Condicionales

  • if — si
  • then — entonces
  • else — sino
  • elseif — sino, si
  • and — y
  • or — o
  • not — no / negar
  • == — es igual a
  • ~= — no es igual a
  • > — es mayor que
  • < — es menor que
  • >= — es mayor o igual que
  • <= — es menor o igual que

Booleanos

  • true — verdadero
  • false — falso

Bucles

  • for — repetir
  • while — mientras
  • repeat — repetir
  • until — hasta que
  • do — hacer / iniciar esto
  • break — detener
  • in — en / dentro de

Funciones

  • function — crear función
  • return — devolver

Tablas

  • { } — crear una tabla
  • [ ] — acceder a un elemento mediante su índice
  • Claves — identificar valores dentro de una tabla

Strings

  • .. — concatenar textos
  • # — obtener la longitud de un string
  • string.upper() — convertir a mayúsculas
  • string.lower() — convertir a minúsculas
  • string.find() — buscar texto

Otros conceptos

  • end — terminar / fin
  • nil — nada / sin valor
  • local — solo aquí
  • goto — ir a
