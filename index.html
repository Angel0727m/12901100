Inicio > Condicionales

Condicionales

Los condicionales permiten que un programa tome decisiones dependiendo de una condición.

if

if significa "si" y comprueba una condición.

if edad >= 18 then
    print("Eres mayor de edad")
end

then

then indica el código que se ejecutará si la condición es verdadera.

else

else ejecuta otro bloque cuando la condición es falsa.

if dinero > 0 then
    print("Puedes comprarlo")
else
    print("No tienes dinero")
end

elseif

elseif permite comprobar otra condición.

if nota >= 5 then
    print("Excelente")
elseif nota >= 3 then
    print("Aprobaste")
else
    print("No aprobaste")
end

and

and requiere que las condiciones necesarias sean verdaderas.

if edad >= 18 and tieneDocumento then
    print("Puede entrar")
end

or

or permite que se cumpla al menos una de las condiciones.

if dia == "sabado" or dia == "domingo" then
    print("Fin de semana")
end

not

not invierte un valor booleano.

jugando = true
print(not jugando)

Comparadores

== igual, ~= diferente, > mayor, < menor, >= mayor o igual y <= menor o igual.

Inicio > Booleanos

Booleanos

Los booleanos solamente pueden tener los valores true o false.

jugando = true
muerto = false

true

Representa un valor verdadero.

false

Representa un valor falso.

Inicio > Bucles

Bucles

Los bucles permiten repetir código varias veces.

while

while repite mientras una condición sea verdadera.

while x < 10 do
    print(x)
    x = x + 1
end

for

for permite repetir utilizando un contador o recorrido.

for i = 1, 5 do
    print(i)
end

repeat

repeat ejecuta el bloque y después comprueba la condición.

repeat
    x = x + 1
until x >= 5

until

until indica hasta qué condición debe repetirse un bloque.

break

break detiene el bucle actual.

for i = 1, 10 do
    if i == 5 then
        break
    end
end

do

do inicia un bloque de código.

in

in se utiliza principalmente para recorrer elementos con ciertos tipos de bucles.

Inicio > Funciones

Funciones

Las funciones son bloques de código reutilizables.

function

function saludar()
    print("Hola")
end

saludar()

return

return devuelve un valor desde una función.

function sumar(a, b)
    return a + b
end

resultado = sumar(3, 2)

Inicio > Tablas

Tablas

Las tablas permiten guardar varios valores dentro de una misma estructura.

Crear una tabla

frutas = {
    "Manzana",
    "Banano",
    "Naranja"
}

Índices

En las tablas tipo lista, Lua normalmente comienza los índices en 1.

print(frutas[1])

Claves

persona = {
    nombre = "Angel",
    edad = 13
}

print(persona.nombre)

Inicio > Strings

Strings

Los strings representan texto.

Crear un string

nombre = "Angel"
print(nombre)

Concatenar

.. une dos strings.

nombre = "Angel"
saludo = "Hola " .. nombre
print(saludo)

Longitud

# obtiene la cantidad de caracteres.

texto = "Hola"
print(#texto)

Inicio > Operadores

Operadores

Los operadores permiten realizar operaciones con valores.

+

+ suma dos valores.

resultado = 5 + 3

-

- resta un valor de otro.

resultado = 5 - 3

*

* multiplica.

resultado = 5 * 3

/

/ realiza una división.

resultado = 10 / 2

//

// realiza una división entera.

resultado = 10 // 3

%

% obtiene el resto de una división.

resto = 10 % 3

^

^ eleva un número a una potencia.

resultado = 2 ^ 3

..

.. concatena strings.

nombre = "Angel"
mensaje = "Hola " .. nombre

#

# obtiene la longitud de un string o la cantidad de elementos de una secuencia.

=

= asigna un valor a una variable.

x = 10

Inicio > Variables

Variables

Las variables permiten guardar valores para utilizarlos después.

local

local crea una variable local.

local edad = 13

Asignación

El operador = asigna un valor.

nombre = "Angel"

Cambiar un valor

Una variable puede recibir un nuevo valor.

x = 5
x = 10

Múltiples variables

Lua permite asignar varios valores al mismo tiempo.

a, b = 10, 20

Intercambiar valores

Puedes intercambiar dos variables directamente.

a, b = b, a

Variable global

Una variable creada sin local puede ser global.

nil

nil representa la ausencia de un valor.

x = nil

Constantes por convención

Lua no tiene constantes simples obligatorias; normalmente se usan nombres en mayúsculas para indicar que no deberían cambiar.

Alcance

El alcance determina en qué partes del programa puede utilizarse una variable.

Inicialización

Inicializar una variable significa darle un valor al crearla.

local vidas = 3

Inicio > Tipos de datos

Tipos de datos

Lua tiene diferentes tipos de valores que pueden almacenarse en variables.

nil

nil representa ausencia de valor.

boolean

boolean representa true o false.

number

number representa números.

edad = 13
precio = 5.5

string

string representa texto.

table

table representa tablas.

function

function representa una función.

userdata

userdata permite representar datos proporcionados por el programa anfitrión.

thread

thread representa un hilo de ejecución de Lua.

type()

type() permite conocer el tipo de un valor.

print(type(25))
print(type("Hola"))

Valores dinámicos

Lua permite que una variable reciba valores de diferentes tipos durante la ejecución.

x = 10
x = "Hola"

Inicio > Funciones básicas

Funciones básicas

print()

print() muestra información en la salida.

print("Hola")

type()

type() indica el tipo de un valor.

print(type(10))

tostring()

tostring() convierte un valor a string.

texto = tostring(123)

tonumber()

tonumber() intenta convertir un valor a número.

numero = tonumber("25")

assert()

assert() comprueba que un valor sea verdadero.

assert(edad >= 0)

error()

error() genera un error en el programa.

error("Ocurrió un problema")

pairs()

pairs() permite recorrer claves y valores de una tabla.

for clave, valor in pairs(persona) do
    print(clave, valor)
end

ipairs()

ipairs() recorre los elementos de una secuencia numérica.

for i, fruta in ipairs(frutas) do
    print(i, fruta)
end

next()

next() permite obtener el siguiente par clave-valor de una tabla.

select()

select() permite trabajar con argumentos variables de una función.

Inicio > Strings y tablas

Strings y tablas

string.len()

string.len() obtiene la longitud de un string.

print(string.len("Hola"))

string.sub()

string.sub() obtiene una parte de un string.

print(string.sub("Hola Mundo", 1, 4))

string.upper()

string.upper() convierte un string a mayúsculas.

string.lower()

string.lower() convierte un string a minúsculas.

string.find()

string.find() busca un texto dentro de otro.

string.match()

string.match() busca una coincidencia utilizando patrones.

string.gsub()

string.gsub() reemplaza partes de un string.

string.format()

string.format() crea un string usando un formato.

table.insert()

table.insert() agrega un elemento a una tabla.

frutas = {"Manzana"}
table.insert(frutas, "Banano")

table.remove()

table.remove() elimina un elemento de una tabla.

table.remove(frutas, 1)
