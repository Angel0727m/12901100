Inicio > Condicionales

Condicionales

Los condicionales permiten que un programa tome decisiones dependiendo de una condición.

if

if significa "si". Comprueba si una condición es verdadera. 

if edad >= 18 then
    print("Eres mayor de edad")
end

then

then indica qué código debe ejecutarse si la condición es verdadera. 

if dinero > 0 then
    print("Tienes dinero")
end

else

else permite ejecutar otro código cuando la condición no es verdadera. 

if dinero > 0 then
    print("Puedes comprarlo")
else
    print("No tienes dinero")
end

elseif

elseif permite comprobar otra condición si la anterior no se cumplió. 

if nota >= 5 then
    print("Excelente")
elseif nota >= 3 then
    print("Aprobaste")
else
    print("No aprobaste")
end

and

and significa "y". Todas las condiciones deben cumplirse para que el resultado sea verdadero. 

if edad >= 18 and dinero > 0 then
    print("Puedes comprarlo")
end

or

or significa "o". Al menos una de las condiciones debe cumplirse para que el resultado sea verdadero. 

if edad >= 18 or tienePermiso then
    print("Puedes entrar")
end

not

not niega una condición e invierte su resultado. 

if not jugando then
    print("El juego terminó")
end

Operadores de comparación

Se utilizan para comparar valores y obtener un resultado verdadero o falso. 

x == 5
x ~= 5
x > 5
x < 5
x >= 5
x <= 5

Inicio > Booleanos

Booleanos

Los booleanos son valores que solamente pueden ser true o false. 

jugando = true
muerto = false

true

Significa que algo es verdadero.

false

Significa que algo es falso.

Inicio > Bucles

Bucles

Los bucles permiten repetir código varias veces.

while

Repite el código mientras la condición sea verdadera. 

while x < 10 do
    print(x)
    x = x + 1
end

for

Repite un bloque de código siguiendo un rango determinado. 

for i = 1, 5 do
    print(i)
end

repeat

Ejecuta un bloque de código y después comprueba una condición. 

repeat
    x = x + 1
until x >= 10

break

Detiene inmediatamente el bucle en el que se encuentra. 

while true do
    break
end

in

Se utiliza en ciertos tipos de for para recorrer elementos de una colección. 

for k, v in pairs(persona) do
    print(k, v)
end

Inicio > Funciones

Funciones

Las funciones son bloques de código que podemos reutilizar cuando los necesitemos.

function

function se utiliza para crear una función. 

function saludar()
    print("Hola")
end

saludar()

return

return devuelve un valor desde una función y termina su ejecución. 

function sumar(a, b)
    return a + b
end

resultado = sumar(5, 3)
print(resultado)

Inicio > Tablas

Tablas

Las tablas permiten guardar varios valores dentro de una misma estructura.

Crear una tabla

Se utilizan llaves { } para crear una tabla. 

frutas = {
    "Manzana",
    "Banano",
    "Naranja"
}

Índices

Los elementos de una tabla pueden accederse mediante su posición. En Lua, los índices normalmente comienzan en 1. 

frutas = {
    "Manzana",
    "Banano",
    "Naranja"
}

print(frutas[1])

Agregar valores

Puedes agregar un nuevo valor indicando su posición. 

frutas = {}

frutas[1] = "Manzana"
frutas[2] = "Banano"

Tablas con claves

Una tabla también puede guardar valores utilizando nombres como claves. 

persona = {
    nombre = "Angel",
    edad = 13
}

print(persona.nombre)

Inicio > Strings

Strings

Los strings son textos. En Lua normalmente se escriben entre comillas.

Crear un string

Puedes guardar texto dentro de una variable utilizando comillas. 

nombre = "Angel"
print(nombre)

Concatenar

El operador .. permite unir dos strings. 

nombre = "Angel"
saludo = "Hola " .. nombre
print(saludo)

Longitud

El operador # permite obtener la cantidad de caracteres de un string. 

texto = "Hola"
print(#texto)

Mayúsculas y minúsculas

Lua tiene funciones para convertir un texto a mayúsculas o minúsculas. 

texto = "Hola Mundo"

print(string.upper(texto))
print(string.lower(texto))

Buscar texto

string.find permite buscar una parte de un string. 

texto = "Hola Mundo"

print(string.find(texto, "Mundo"))

Inicio > Diccionario completo

Diccionario completo

Aquí están reunidos todos los conceptos de LuaLex con su significado y regla de uso.

Condicionales

  • if — si. Comprueba si una condición se cumple.
  • then — entonces. Indica qué código se ejecuta si la condición es verdadera.
  • else — sino. Se ejecuta cuando la condición anterior es falsa.
  • elseif — sino, si. Comprueba otra condición cuando la anterior es falsa.
  • and — y. Todos los resultados deben cumplirse para que sea verdadero.
  • or — o. Al menos uno de los resultados debe cumplirse para que sea verdadero.
  • not — no / negar. Invierte el resultado de una condición.
  • == — es igual a. Comprueba si dos valores son iguales.
  • ~= — no es igual a. Comprueba si dos valores son diferentes.
  • > — es mayor que. Comprueba si el primer valor es mayor que el segundo.
  • < — es menor que. Comprueba si el primer valor es menor que el segundo.
  • >= — es mayor o igual que. Comprueba si el primer valor es mayor o igual al segundo.
  • <= — es menor o igual que. Comprueba si el primer valor es menor o igual al segundo.

Booleanos

  • true — verdadero. Representa una condición verdadera.
  • false — falso. Representa una condición falsa.

Bucles

  • for — repetir. Repite un bloque de código siguiendo un rango o una colección.
  • while — mientras. Repite el código mientras la condición sea verdadera.
  • repeat — repetir. Ejecuta el código y después comprueba la condición.
  • until — hasta que. Detiene un bloque repeat cuando la condición se vuelve verdadera.
  • do — hacer / iniciar esto. Indica el comienzo del bloque de código de ciertos bucles.
  • break — detener. Detiene inmediatamente el bucle.
  • in — en / dentro de. Se utiliza para recorrer elementos de una colección con ciertos tipos de for.

Funciones

  • function — crear función. Define un bloque de código reutilizable.
  • return — devolver. Devuelve un valor desde una función y termina su ejecución.

Tablas

  • { } — crear una tabla. Las llaves contienen los valores de una tabla.
  • [ ] — acceder a un elemento. Se utiliza para acceder a un valor mediante su índice o clave.
  • Claves — identificar valores. Permiten guardar y acceder a valores mediante un nombre.

Strings

  • .. — concatenar textos. Une dos o más strings.
  • # — obtener longitud. Devuelve la cantidad de caracteres de un string.
  • string.upper() — convertir a mayúsculas. Convierte las letras de un string a mayúsculas.
  • string.lower() — convertir a minúsculas. Convierte las letras de un string a minúsculas.
  • string.find() — buscar texto. Busca una parte específica dentro de un string.

Otros conceptos

  • end — terminar / fin. Indica el final de un bloque de código.
  • nil — nada / sin valor. Representa la ausencia de un valor.
  • local — solo aquí. Crea una variable con alcance local.
  • goto — ir a. Salta la ejecución hacia una etiqueta determinada.
