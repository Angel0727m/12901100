Inicio > Condicionales

Condicionales

Los condicionales permiten que un programa tome decisiones dependiendo de una condición.

if

if significa "si". Se utiliza para comprobar si una condición es verdadera. 

if edad >= 18 then
    print("Eres mayor de edad")
end

then

then indica qué código debe ejecutarse si la condición es verdadera. 

if dinero > 0 then
    print("Tienes dinero")
end

else

else permite ejecutar otra cosa cuando la condición no es verdadera. 

if dinero > 0 then
    print("Puedes comprarlo")
else
    print("No tienes dinero")
end

elseif

elseif permite comprobar otra condición si la anterior no se cumplió. 

if nota >= 5 then
    print("Excelente")
elseif nota >= 3 then
    print("Aprobaste")
else
    print("No aprobaste")
end

Inicio > Booleanos

Booleanos

Los booleanos son valores que solamente pueden ser true o false. 

jugando = true
muerto = false

true

Significa que algo es verdadero.

false

Significa que algo es falso.

Inicio > Bucles

Bucles

Los bucles permiten repetir código varias veces.

while

while x < 10 do
    print(x)
    x = x + 1
end

for

for i = 1, 5 do
    print(i)
end

function saludar()

Inicio > Tablas

Tablas

Las tablas permiten guardar varios valores dentro de una misma estructura.

Crear una tabla

Se utilizan llaves { } para crear una tabla. 

frutas = {
    "Manzana",
    "Banano",
    "Naranja"
}

Índices

Los elementos de una tabla pueden accederse mediante su posición. En Lua, los índices normalmente comienzan en 1. 

frutas = {
    "Manzana",
    "Banano",
    "Naranja"
}
print(frutas[1])

Agregar valores

Puedes agregar un nuevo valor indicando su posición. 

frutas = {}
frutas[1] = "Manzana"
frutas[2] = "Banano"

Tablas con claves

Una tabla también puede guardar valores utilizando nombres como claves. 

persona = {
    nombre = "Angel",
    edad = 13
}
print(persona.nombre)

Inicio > Strings

Strings

Los strings son textos. En Lua normalmente se escriben entre comillas.

Crear un string

Puedes guardar texto dentro de una variable utilizando comillas. 

nombre = "Angel"
print(nombre)

Concatenar

El operador .. permite unir dos strings. 

nombre = "Angel"
saludo = "Hola " .. nombre
print(saludo)

Longitud

El operador # permite obtener la cantidad de caracteres de un string. 

texto = "Hola"
print(#texto)

Mayúsculas y minúsculas

Lua tiene funciones para convertir un texto a mayúsculas o minúsculas. 

texto = "Hola Mundo"
print(string.upper(texto))
print(string.lower(texto))

Buscar texto

string.find permite buscar una parte de un string. 

texto = "Hola Mundo"
print(string.find(texto, "Mundo"))
