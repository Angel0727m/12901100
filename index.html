Inicio > Tablas

Tablas

Las tablas permiten guardar varios valores dentro de una misma estructura.

Crear una tabla

Se utilizan llaves { } para crear una tabla. 

frutas = {
    "Manzana",
    "Banano",
    "Naranja"
}

Índices

Los elementos de una tabla pueden accederse mediante su posición. En Lua, los índices normalmente comienzan en 1. 

frutas = {
    "Manzana",
    "Banano",
    "Naranja"
}
print(frutas[1])

Agregar valores

Puedes agregar un nuevo valor indicando su posición. 

frutas = {}
frutas[1] = "Manzana"
frutas[2] = "Banano"

Tablas con claves

Una tabla también puede guardar valores utilizando nombres como claves. 

persona = {
    nombre = "Angel",
    edad = 13
}
print(persona.nombre)

Inicio > Strings

Strings

Los strings son textos. En Lua normalmente se escriben entre comillas.

Crear un string

Puedes guardar texto dentro de una variable utilizando comillas. 

nombre = "Angel"
print(nombre)

Concatenar

El operador .. permite unir dos strings. 

nombre = "Angel"
saludo = "Hola " .. nombre
print(saludo)

Longitud

El operador # permite obtener la cantidad de caracteres de un string. 

texto = "Hola"
print(#texto)

Mayúsculas y minúsculas

Lua tiene funciones para convertir un texto a mayúsculas o minúsculas. 

texto = "Hola Mundo"
print(string.upper(texto))
print(string.lower(texto))

Buscar texto

string.find permite buscar una parte de un string. 

texto = "Hola Mundo"
print(string.find(texto, "Mundo"))
