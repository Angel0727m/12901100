Inicio > Variables y alcance

NIVEL 1

Variables y alcance

Las variables permiten guardar valores para utilizarlos después.

local

local vidas = 3

print(vidas)

Usar local crea una variable con alcance local. Es la forma habitual de declarar variables.

Variables globales

Lua 5.5 también incluye una declaración explícita para variables globales. 

global nombre

nombre = "Lua"

const

local <const> PI = 3.14159

<const> indica que la variable local no puede ser reasignada.

close

local <close> recurso = obtenerRecurso()

Los valores marcados con <close> pueden ejecutar su comportamiento de cierre al salir de su alcance.

_ENV y _G

_ENV representa el entorno utilizado para resolver nombres globales. _G es la referencia convencional al entorno global.

Consejo: cuando estés empezando, usa local casi siempre.

Tipos de datos

Inicio > Booleanos

Booleanos

Lua tiene dos valores booleanos: true y false. 

local jugando = true
local terminado = false
Muy importante: en Lua solamente false y nil son falsos en una condición. 0 y "" son verdaderos.

Operadores lógicos

if edad >= 13 and edad <= 17 then
    print("Adolescente")
end

if dia == "sabado" or dia == "domingo" then
    print("Fin de semana")
end

print(not true)

Inicio > Funciones

Funciones

Crear una función

local function saludar(nombre)
    print("Hola " .. nombre)
end

saludar("Lua")

Parámetros y return

local function sumar(a, b)
    return a + b
end

local resultado = sumar(3, 4)

print(resultado)

Funciones anónimas

local doble = function(numero)
    return numero * 2
end

print(doble(5))

Varargs

local function contar(...)
    return select("#", ...)
end

Closures

local function crearContador()

    local numero = 0

    return function()

        numero = numero + 1

        return numero

    end

end
Las funciones son valores de primera clase: puedes guardarlas en variables, pasarlas a otras funciones y devolverlas.

Inicio > Tablas

Tablas

Crear una tabla

local frutas = {
    "Manzana",
    "Banano",
    "Naranja"
}

Acceder a elementos

print(frutas[1])
print(frutas[2])

Tablas con claves

local persona = {
    nombre = "Lua",
    edad = 10
}

print(persona.nombre)
print(persona["edad"])

Insertar y eliminar

table.insert(frutas, "Pera")

table.remove(frutas, 1)

Recorrer

for i, fruta in ipairs(frutas) do
    print(i, fruta)
end

for clave, valor in pairs(persona) do
    print(clave, valor)
end
Una tabla puede tener distintas claves. Las secuencias normalmente comienzan en el índice 1.

Inicio > Metatables

Metatables

Las metatables permiten personalizar determinados comportamientos de valores. 

local persona = {
    nombre = "Angel"
}

local meta = {

    __tostring = function(tabla)
        return "Persona: " .. tabla.nombre
    end

}

setmetatable(persona, meta)

print(persona)

Inicio > Coroutines

Coroutines

Permiten suspender y reanudar una ejecución de Lua de forma cooperativa. 

local co = coroutine.create(function()

    print("Uno")

    coroutine.yield()

    print("Dos")

end)

coroutine.resume(co)

coroutine.resume(co)

Conceptos: create, resume, yield, status, running, wrap, isyieldable y close.
