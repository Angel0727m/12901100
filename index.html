Diccionario completo

Aquí están reunidos todos los conceptos de LuaLex.

Condicionales

  • if — si. Comprueba si una condición se cumple.
  • then — entonces. Indica qué código se ejecuta si la condición es verdadera.
  • else — sino. Se ejecuta cuando la condición anterior es falsa.
  • elseif — sino, si. Comprueba otra condición cuando la anterior es falsa.
  • and — y. Todos los resultados deben cumplirse para que sea verdadero.
  • or — o. Al menos uno de los resultados debe cumplirse para que sea verdadero.
  • not — no / negar. Invierte el resultado de una condición.
  • == — es igual a. Comprueba si dos valores son iguales.
  • ~= — no es igual a. Comprueba si dos valores son diferentes.
  • > — es mayor que. Comprueba si el primer valor es mayor que el segundo.
  • < — es menor que. Comprueba si el primer valor es menor que el segundo.
  • >= — es mayor o igual que. Comprueba si el primer valor es mayor o igual al segundo.
  • <= — es menor o igual que. Comprueba si el primer valor es menor o igual al segundo.

Booleanos

  • true — verdadero. Representa una condición verdadera.
  • false — falso. Representa una condición falsa.

Bucles

  • for — repetir. Repite un bloque de código siguiendo un rango o una colección.
  • while — mientras. Repite el código mientras la condición sea verdadera.
  • repeat — repetir. Ejecuta el código y luego comprueba la condición.
  • until — hasta que. Detiene un bloque repeat cuando la condición se vuelve verdadera.
  • do — hacer / iniciar esto. Indica el comienzo del bloque de código de ciertos bucles.
  • break — detener. Detiene inmediatamente el bucle en el que se encuentra.
  • in — en / dentro de. Se utiliza para recorrer elementos de una colección con ciertos tipos de for.

Funciones

  • function — crear función. Define un bloque de código reutilizable.
  • return — devolver. Devuelve un valor desde una función y termina su ejecución.

Tablas

  • { } — crear una tabla. Las llaves contienen los valores de una tabla.
  • [ ] — acceder a un elemento. Se utiliza para acceder a un valor mediante su índice o clave.
  • Claves — identificar valores. Permiten guardar y acceder a valores mediante un nombre.

Strings

  • .. — concatenar textos. Une dos o más strings.
  • # — obtener longitud. Devuelve la cantidad de caracteres de un string.
  • string.upper() — convertir a mayúsculas. Convierte las letras de un string a mayúsculas.
  • string.lower() — convertir a minúsculas. Convierte las letras de un string a minúsculas.
  • string.find() — buscar texto. Busca una parte específica dentro de un string.

Otros conceptos

  • end — terminar / fin. Indica el final de un bloque de código.
  • nil — nada / sin valor. Representa la ausencia de un valor.
  • local — solo aquí. Crea una variable con alcance local.
  • goto — ir a. Salta la ejecución hacia una etiqueta determinada.
